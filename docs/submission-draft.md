```text
SecondLine gives individuals a short way to rehearse a safe pause before an urgent request for a one-time code or payment. In a clearly fictional English scenario, an agent built on the AssemblyAI Voice Agent API speaks one pressure line. The learner answers aloud with a boundary and explains how they would verify the claim through an official app or contact route found independently. The browser shows the final transcript turns from that exercise. A deterministic reflection quotes captured pressure words, highlights only practice steps supported by the learner's response, and suggests a next try. It does not score the caller or decide whether a real request is genuine. The API key stays on the server; the browser uses a short-lived token. The public prototype uses real AssemblyAI voice infrastructure and has completed a synthetic browser-microphone test. SecondLine never joins a real call, contacts an institution, requests an actual code, or moves money. Financial-literacy educators could use short exercises like this to help learners practice a response in their own words. That is a use hypothesis: we have not measured learning outcomes, fraud prevention, or real adoption.
```
