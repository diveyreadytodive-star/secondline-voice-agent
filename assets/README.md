# Cover asset

`cover-final.png` is the 1600 × 900 image for the hackathon submission form. It combines an AI-generated fictional editorial still life with exact title text set locally in Georgia Bold and Avenir Next. The blank phone screen and notebook do not depict an actual incident, call, or financial transaction.

`cover-art.png` is the unlettered generated source. Generated with the built-in Codex image tool for this project using this prompt:

> A premium editorial still-life illustration showing a mobile phone lying face up with a completely blank dark screen, beside an open notebook with one empty line and a capped coral red pen, communicating a deliberate pause before answering a pressured request. Warm ivory paper surface, dark charcoal shadows, restrained coral accent, subject grouped on the right half, left half quiet for title text. Soft directional daylight, sophisticated editorial photography blended with subtle paper-cut illustration. No real bank, caller identity, logos, people, cash, security badges, fraud-score graphics, letters, numbers, or watermark.

The final cover uses the source image once and makes the title readable against its blank paper area.
